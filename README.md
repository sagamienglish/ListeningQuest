# ListeningQuest

日本人英語学習者向けの、ミニマルペア聞き分けトレーニングWebアプリのプロトタイプです。

## 現在できること

- Phase 1は8カテゴリー、Phase 2は9カテゴリー（合計170ペア）
- Phase 1・2ごとの、異なる5カテゴリーからのランダム出題
- Phase別メニューの上に独立表示する、Phase 1〜3共通の総合レベル判定
- ホーム最上段を色分けした「音声トレーニング／総合レベルテスト／苦手リトライ」の学習モード切り替えとして表示
- モード選択時は即開始せず、下部に学習進捗・概要・開始ボタンを表示
- トレーニング内はPhase 1〜3の大きなカードに整理し、各カード内から「ランダム5題」を直接開始
- 各PhaseのレートをLEVELゲージで表示し、次のレベルまでに必要なレートを可視化
- 総合レベル判定は5問を縦に並べて1画面に表示し、全回答後に一括採点
- 総合レベル判定では正誤と回答速度から専用の総合レート・レベルが上下
- 誤答した設問を最大40件保存し、直近5件を再出題する「苦手分野攻略」
- 正誤と回答速度によって上下する段階別レート・レベル
- Phase 1・2はAva (Premium)で収録した単語・短文680音声による通常・低速再生
- 選択肢で単語・IPA・日本語の意味を確認
- 左右矢印、Space、S、Enterキーによる操作
- レート・レベル・カテゴリー習熟度と最近30回のレート推移を端末内保存
- 回答履歴から正答率の低いカテゴリーを「重点項目」として最大3件表示
- 判定結果では直前の位置から現在位置までLEVELゲージが伸びるアニメーションを表示
- 正解・不正解の効果音とフィードバックアニメーション
- ランダム5問のうち2問を短文で出題
- 音声終了後に減っていくスピードレートバー
- 5問後に上下の単語を選んで経路を作る、地球から8天体への仕上げルートクイズ
- 選択した経路をテーマカラー、正解した全経路を緑で表示
- カテゴリー一覧から代表ペアを試聴
- カテゴリーは番号・発音記号・進捗を初期表示し、押したカードだけ名称・個別練習・サンプルを展開
- ミニマルペアの代表2語はサンプル再生後に上下2段で表示
- Phase 3のconnected speech 9カテゴリー・90問
- Phase 3も異なる5カテゴリーからランダム出題し、レート・習熟度を更新
- Phase 3は各カテゴリーから5問を選ぶ個別練習にも対応
- Phase 3のカテゴリーカードは短い日本語名と習熟度を常時表示
- Phase 3はターゲット語句を空欄にし、正解語と似た音のダミー語から左→右の順で復元
- Phase 3の文の強弱・リズムでは、通常の大小文字で示した文から、強調表示された指定語数だけ強く読むべき語を選択
- `want to` のように連結後に聞こえやすい `a` も類似音の選択肢として出題
- Phase 3の回答後は上の正解文にも音のつながりや変化を直接表示し、下部に詳しいListening Pointを表示
- フラップ音は変化するt/dだけを下線表示し、hisなどの弱形は弱くなるhの下に△を表示
- Phase 3ホームに総合習熟度、カテゴリー別習熟度バー、レート推移を表示
- 結果画面の正答率リングを得点の割合だけテーマカラーで描画
- Phase 3カードから各カテゴリーの代表音声を試聴
- Google AI Studioで収録した3本のマスター音声を90個の設問別WAVへ切り出して再生
- 地球を出発点にし、右側は地球を除いた7惑星と月をCSSイラストで表示
- 仕上げルートは単語または中央ノードで選択し、不正解時は天体直前の最後の線だけを候補から除外
- 不正解だった行き先の天体はグレー表示にして、除外済みであることを明示
- 右端を含む各分岐から上・下2本の線を表示
- 最終ノードの上・下分岐と到着天体の対応を固定し、選択ルートと表示線を一致
- ギブアップ時は正解ルートを表示し、正解の5音を自動再生（天体ボーナスなし）
- iPad、スマートフォン、PC向けレスポンシブUI

## 起動方法

このフォルダーで次を実行し、ブラウザで `http://127.0.0.1:4173` を開きます。

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Phase 1・2は `audio/phase1/` と `audio/phase2/` の収録済みWAVを再生します。Phase 3は `audio/Phase3-1.wav` 〜 `Phase3-3.wav` から生成した設問別音声を再生します。いずれも設問ごとに独立したファイルのため、別の音声へずれることがありません。

## ファイル

- `index.html` — アプリの入口
- `styles.css` — デザインとレスポンシブ対応
- `app.js` — ランダム出題、速度計測、音声、レート計算、進捗保存
- `data.js` — 承認済み17カテゴリー・170ペア
- `phase3-data.js` — Phase 3の9カテゴリー・90問
- `phase3-audio-map.js` — 90問と設問別WAVの対応表
- `audio/Phase3-1.wav` 〜 `audio/Phase3-3.wav` — Phase 3の収録済みマスター音声
- `audio/phase3-recorded/` — マスター音声から切り出した90個の実再生用WAV
- `audio/phase3/` — マスター音声がない場合のフォールバック用WAV音声
- `audio/phase1/` — Phase 1の単語・短文320個のWAV
- `audio/phase2/` — Phase 2の単語・短文360個のWAV
- `scripts/build-phase12-audio.mjs` — Phase 1・2の680音声をmacOS音声から再生成
- `scripts/build-data.mjs` — 元の教材作成スクリプトから `data.js` を再生成
- `scripts/build-phase3-assets.mjs` — Phase 3データ・音声・Excelの生成
- `scripts/build-phase3-ai-studio-prompt.mjs` — 90文を1本に収録するGoogle AI Studio用プロンプトの生成
- `scripts/analyze-phase3-master.py` — マスター音声の無音区間を解析
- `scripts/split-phase3-master.py` — 3本のマスター音声を90個の設問別WAVへ分割
- `scripts/build-phase3-audio-map.mjs` — 解析結果から90問の区間対応表を生成
- `outputs/phase3_connected_speech_v1/ListeningQuest_Phase3_90_questions.xlsx` — Phase 3レビュー用Excel
- `outputs/phase3_audio_master/` — Google AI Studio用プロンプトと90文キューシート
